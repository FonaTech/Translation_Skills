# Content contract v1.0

Projects contain project.json, content.json, source copies, assets, previews, tasks, outputs and reports. Work outside the installed skill. Portable paths are relative.

Manifest fields: title, target_languages, source_language/auto, editions, style, page_size, columns, per-language direction, image_label_policy, optional author_credit. No brand, subject, language pair or units are hardcoded.

Sources retain id/name/hash/media_type/page_count/selection_scope/rights. Ordered blocks retain id/type/source document+page+bbox or element, units and table rows/assets/heading level. Each unit has id/source/translations keyed by language and faithful/interpretive fields. Table cells are unit IDs, including explicit blank units. Image caption/alt units or explicit no-text records accompany assets.

Block types include `reference` for bibliography entries. Figure label policies are `unreviewed`, `translated`, `no-text` and `retained-original`; the legacy `retained-with-note` token remains schema-compatible. Retained original labels require an explicit exception note and source/output inspection; a translated caption or separate label map does not mean the labels were replaced in the figure.

Exchange: {"language":"zh-Hans","items":[{"id":"D001-B0001-U001","faithful":"...","interpretive":"...","note":"..."}]}. Apply rejects unknown/duplicate IDs, missing editions and empty translations for nonempty sources. It does not mark review complete.

Reviews bind reviewer label, kind, content hash, full/partial scope, notes and time. Visual records also bind artifact hashes. Edits invalidate old reviews. A record is not proof or certification. Splits/merges preserve correction notes and row references. Code passthrough must be explicit.

Formal JSON schemas are in [schemas/project.schema.json](schemas/project.schema.json), [schemas/content.schema.json](schemas/content.schema.json) and [schemas/packet.schema.json](schemas/packet.schema.json). Runtime audit also checks cross-references and completeness, which schemas alone cannot prove. Packets generated by tasks include expected_ids and an extraction-only source_hash; preserve both during translation. A sparse patch omitting expected_ids is permitted, but does not claim full packet completion.

For a reviewed note revision, a packet item can supply replace_notes as a list of distinct strings (or an empty list to remove stale notes) instead of note. This replaces only notes for that target language and logs the previous notes. Resolve redundant notes explicitly; do not let repeated applications accumulate paraphrases of the same uncertainty. Bibliography paragraphs use the presentation role bibliography rather than metadata, so citations retain readable contrast and type size. Source bibliography defects remain unchanged and separately noted.
