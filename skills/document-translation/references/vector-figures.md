# Vector figures and label translation

PDF vector drawings are page commands and may have no embedded bitmap. Ingestion automatically proposes source-bound composite crops from raster footprints, connected vector regions and the parser's caption/label geometry. Pure vector figures trigger SVG export with an opaque source-PNG fallback; mixed artwork is cropped in PDF context to retain paths, masks and labels. Geometry confidence is a heuristic score, not a calibrated probability or semantic figure detector.

Automatic image candidates enter the translation/reading IR only when linked to a nonempty same-page caption block. Unbound artwork stays in reports/figure-regions/ with its crop and text evidence; do not translate it as an illustration or insert it in the reading edition. Missing binding does not establish that an object is not a figure. Keep original prose, tables, equations and explicit page-image/OCR evidence intact. Do not invent a caption to admit a candidate. The figure-policy PROJECT command migrates legacy automatic image blocks losslessly to the audit archive; tasks, build and render enforce the same rule. After source inspection an explicit manual crop remains available.

Every automatic or manual crop archives native text in an adjacent .text.json and .text.txt: character boxes, native line IDs, font/size/flags, directions, source page/bounds and nearby caption context. The image block's hash-bound crop_text points to this ledger. Crop pixels remain the evidence when text is outlined, scanned, missing or garbled; request OCR/vision review instead of inventing text. Short native label blocks wholly contained in one caption-bound crop are automatically rehomed to that image's source_label_blocks archive, retaining IDs, text and typography. Partial intersections and long narrative remain active prose. Inspect this ownership proposal and declare retained-original labels explicitly unless actual translated label units exist. Archived labels are not duplicated in body translation tasks.

reports/figure-regions/ records automatic bounds, trigger, caption candidate IDs and pending review. tasks includes a figure-context index and related-figure references with the crop and text-ledger paths. Read these files and inspect a wider source region to reconstruct the caption from visible source text, including wrapped or cross-column continuations. Never synthesize an absent caption. Only verified caption IDs should remain bound before publishing.

reports/source-layout/ is the hash-bound parser-to-layout handoff: ordered blocks, source boxes, typography, column-band proposals, figures, captions and footnote relations. The source-first layout planner reads this map and uses corroborated column evidence; output blocks retain source geometry/order hints. Translation reflows at the target language's length, so reconstruction preserves hierarchy and spatial relationships rather than identical pagination. Inspect and refine renders before any closest-template fallback. If source blocks change, regenerate the map with python3 scripts/translate.py layout-map PROJECT.

Disconnected panels, ambiguous top/bottom captions, multi-caption plates and scanned pages still require the agent to verify complete bounds. Automatic proposals never certify a complete figure.

After inspecting the source, run:

    python scripts/translate.py crop PROJECT --document D001 --page 3 --bbox X0,Y0,X1,Y1 --width 170 --format auto

Auto preserves intersecting vector paths as static SVG with a source-rendered PNG fallback. Explicit svg fails when unsupported; png deliberately rasterizes. Rotated pages require normalization and visual checking or a recorded PNG fallback. Text is outlined to preserve source font appearance. Outlines are not editable or automatically translated text. Mixed figures retain bitmap pixel dimensions. Risky CMYK/ICC/Decode images are decoded inside a temporary copy of the source PDF and converted losslessly to RGB before SVG serialization. Never invert a standalone extracted JPEG or force genuine dark artwork to white. Soft masks and vector paths remain intact; the original PDF is never edited.

Compare all edges, panels, axes, legends, units, arrowheads, overbars and transparency. Bind the same-page caption and place the figure at the correct reading position. Account for every visible natural-language label as source units. A retained original plus translated label map is not in-place label replacement: record retained-original and disclose the exception. Replacing labels requires separate verified overlays; never change data curves or invent missing text. Faithful translation never completes the source.

HTML and Chromium PDF use SVG. Editor imports and HTML exports preserve supported static SVG. DOCX contains SVG and a PNG compatibility fallback, and both can be reimported. Whole-figure size and placement are editable; individual circuit paths and outlined labels are not Word shapes. Word/LibreOffice display requires native visual review. Compare source and rendered page images after layout changes; path counts do not prove semantic or visual fidelity.

## Mandatory source-appearance gate

Both `build` and `render` call `scripts/asset_fidelity.py`. It renders every retained-original PDF figure from its declared source page/bounds in opaque RGB, decodes the actual SVG/raster in Chromium, and compares source-relative color error and newly black regions. It also checks PNG compatibility fallbacks. Old SVGs migrate through the source-aware exporter. When SVG appearance still differs, use an opaque RGB PNG rendered from the same source crop and record the lost vector capability. This is an image-fidelity fallback, not permission to switch document templates.

Results live in `reports/asset-fidelity.json`, with source/asset/evidence hashes and comparison metrics. `release` rejects missing/stale coverage or failed final metrics. Out-of-page PDF image transforms are clipped to the actual visible page; wholly off-page/invalid crops stop the workflow. Do not treat metric success as label, extraction-completeness or aesthetic review. Compare panels, masks, small details and output-page placement visually.

For intentionally translated labels or sources without a comparable PDF crop, retain the native-source visual-review requirement. Never overwrite a translated graphic with its source just to pass pixel comparison. The existing page-evidenced visual review remains required. The editor rejects four-component JPEGs even with a spoofed MIME. A supplied static PNG fallback can be used for legacy import; otherwise the missing/unsafe image blocks export. HTML/PDF/DOCX exports recheck current images; DOCX compatibility images are generated from the browser-decoded current figure.

Run the author-owned regression in a fresh directory:

    python3 tools/asset_fidelity_regression.py --output /path/to/fresh-test-directory --browser /path/to/chromium

It exercises CMYK, explicit RGB/gray Decode, soft masks, original dark art, pure vectors, incorrect main/fallback images, stale evidence, HTML/PDF rendering, legacy editor import and DOCX round trips. Thresholds are conservative engineering tolerances, not calibrated guarantees for arbitrary PDFs or substitutes for source/output visual comparison.

PDF verification maps print CSS pixels to points at 96 px / 72 pt; rounded PDF page dimensions are not used as independent axis scaling. Source crops are placed at the declared destination on an empty comparison page and rasterized on the same physical pixel grid as the actual PDF, with no offset search or threshold relaxation. Static untransformed graphics can receive a bounded, recorded pixel-grid alignment during pagination to avoid Chromium destination rounding. Alignment is rejected if it creates a collision or overflow; aspect ratio changes are tightly bounded. Editable source parameters stay intact; inspect small labels and symbols after export. The crop command defaults to the source crop physical width; specify --width only when a different verified figure scale is needed.

A crop comparison verifies the declared region, not whether the region includes the entire figure. Before accepting its bounds, inspect a larger source region around all four edges; check disconnected labels, arrowheads, legends and preceding prose. Repair the crop from the original PDF, preserve a before/after ledger, and rerender both reading editions and alignment. Pixel alignment is withdrawn if it would cross the content area or collide with an adjoining caption.
