# Source structure learning and evaluation

Use this procedure when native text has wrong reading order, fragmented inline
math, merged columns, misplaced captions or excessive paragraph splitting. This
experimental parser proposes roles and paragraph links. It does not translate,
recover missing words, transcribe arbitrary equations or certify extraction.
Read the separate [source model card](../assets/models/SOURCE_STRUCTURE_MODEL_CARD.md)
for architecture, dependencies, training provenance and limits.

## Evidence and labels

Keep the source PDF, source SHA-256, every native line/span/character with its
coordinates, font, size and immutable IDs. `raw_page` joins compatible physical
fragments while retaining `native_line_ids`, original spans and fragment boxes.
Nested inline fragments use character coordinates rather than PDF object order.
`inline_glyph_runs` retains original glyph sizes and positions; the plain text
alone does not preserve superscripts, subscripts or equation semantics. Never
present plain flattened math as a verified equation tree.

Author labels by inspecting the source page and its native evidence before
opening predictions. `_role` uses these distinct classes:

| Role | Source content |
| --- | --- |
| body | Narrative, abstract, acknowledgments and explanatory prose |
| title | Main document title |
| heading | Section or subsection heading, including its printed number |
| metadata | Authors, affiliations, keywords/index terms, dates, identifiers, running furniture, licensing and ancillary footnotes |
| caption | Figure/table title and its description outside the actual cells |
| reference | Bibliographic entries and their continuation lines |
| equation | Display formula fragments; spatial evidence is required |
| label | Diagram/plot labels, axes, ticks and subfigure markers |
| table | Actual table-cell content, including column and row headings |
| list | Source list items and their continuation lines |

Roles determine presentation, never permission to discard source material.
Metadata and labels remain in the source ledger and translation scope. Mark
unclear assembly with `_assembly_unresolved`; do not guess a target. `_group`
identifies one source paragraph/item/caption/reference. `_order_regions` is an
explicitly authored sequence of source-row regions; text inside an unordered
diagram region is spatial content, not a prose chain. A native PDF block can
contain several roles and paragraphs, so its number is not ground truth.

Freeze the annotation JSON and SHA-256 before fitting or testing. Log corrections
in a new revision; retain the initial test annotations and report. Agent labels
are not independent human gold. Repeated ligature codes can represent a radical
rule with a broken text map; retain the evidence and compare the raster rather
than expanding it into invented prose. For display equations, a numbered
spatial envelope and nearby math-font evidence may keep damaged native rows in
the same reviewable visual region. Preserve exact control/replacement glyphs,
mark them unresolved, and never treat spatial membership as symbol recovery or
verified equation transcription.

## Iteration and source separation

Split by the original whole-document hash, including aliases and duplicate PDFs.
For repaired, OCR or converted copies, record `source_parent_sha256` with all
original/ancestor hashes. Preparation accepts repeatable
`--source-parent-sha256`; training and evaluation reject overlapping declared
source families. See [font-map recovery](font-map-recovery.md) for an example.
An error-analyzed test document becomes development data in the next round. Do
not take a different page of that source as a fresh test. Reserve additional
complete sources before training and stratify by actual prose-column layout;
three columns of figures do not establish a three-column prose test.

From the repository root, the executable loop is:

```sh
python3 tools/prepare_structure_annotations.py PRIVATE/new-source.pdf --split test --output PRIVATE/source-evidence
# Inspect every source PNG and native row; author roles, groups, reading regions
# and unresolved reasons in a separate PRIVATE/authored-labels.json. No prediction
# is generated by preparation. Do not replace missing labels with model outputs.
python3 tools/freeze_structure_annotations.py --annotations PRIVATE/authored-labels.json --output PRIVATE/frozen-unseen.json
python3 tools/refresh_structure_annotations.py --annotations PRIVATE/development.json --output PRIVATE/development-refreshed.json --audit PRIVATE/refresh-audit.json
python3 tools/train_source_structure.py --annotations PRIVATE/development-refreshed.json --documents 140 --epochs 180 --seed 173 --output PRIVATE/model.json --evidence PRIVATE/training.json
python3 tools/structure_corpus.py evaluate --annotations PRIVATE/frozen-unseen.json --model PRIVATE/model.json --inventory PRIVATE/inventory.json --output PRIVATE/test-report.json
python3 tools/structure_review.py --annotations PRIVATE/frozen-unseen.json --model PRIVATE/model.json --output PRIVATE/source-review.html
```

`PRIVATE` means a user-authorized work directory outside the skill repository.
Preparation refuses existing output folders and duplicate whole-source aliases.
Freezing requires every source page and every nonblank row's explicit labels,
then re-extracts the native text and geometry from the hash-identified PDF. It
rejects edited source rows, profiles and geometry, and writes a SHA-256 sidecar.
These checks do not prove that the author inspected the source, or that the
labels are correct. Keep their provenance and any unresolved content explicit.
Annotation refresh refuses changed native text or conflicting role/group labels;
inspect those conflicts against the source before proceeding. Regenerate raw
evidence for unseen PDFs when the extraction revision changes, then author and
freeze new labels before opening predictions. Training requires NumPy; portable
inference can use standard-library arithmetic. The optional tree comparator needs
scikit-learn/SciPy for fitting only and uses original portable tree traversal at
inference. See `THIRD_PARTY_NOTICES.md` for optional dependency licenses.

The role head uses typography, source text patterns, document context and
geometry. The link head scores proposed physical-line adjacency. A path decoder
enforces at most one predecessor/successor with role, direction, table-cell and
geometry gates. Geometric penalties and scale-consistency losses are document
constraints; they are not a PDE-based physics model. Softmax scores are not
calibrated correctness probabilities. Do not lower thresholds after inspecting
test labels and call the result a new independent test.

## Acceptance and limits

Evaluate the actual extraction/role/link/order pipeline, not just isolated
classifier pairs. Record model, pipeline, source and annotation hashes. Report
per-document role accuracy, prose/code/note link precision/recall/F1, exact
ordered prose-group accuracy, equation-region membership, region reading-order
accuracy and unresolved truth coverage. Equation glyphs can be stored as
independent two-dimensional fragments: compare exact unordered source-row
membership for each display, never classify object-order edges as prose
continuations. This metric does not score symbol transcription, equation
topology or mathematical correctness. Exact prose groups require the complete
ordered row sequence and role, not merely most adjacent links.
An unresolved or excluded group cannot count as exactly reconstructed. Pairwise
reading-order scores can be high despite visible local errors; source review and
exact grouping remain necessary.
If there are no eligible or predicted edges, link scores are `null` and marked
unmeasured. An undefined denominator must never count as perfect reconstruction.

`certification_gate` requires all expected sources and every page, complete truth,
each required metric at least 99%, and separately source-verified table,
equation, figure-ownership and text-integrity results. A corpus scan measures
preservation and flags only; it does not measure correctness without truth.
Page-local group accuracy cannot certify paragraphs continued onto another page;
the gate also requires separately reviewed `cross_page_assembly` evidence.
Synthetic holdouts, trained-source scores and fresh-source scores must be shown
separately. No current model is certified to parse arbitrary PDFs at 99%.

When increasing model capacity, compare matched random seeds, source splits,
real annotations, epoch counts and inference pipeline. Report the number of
trainable weights and biases per head and compare final document reconstruction,
not raw training accuracy. If a larger model improves fit but lowers held-out
or exact-group performance, retain it as a diagnostic candidate rather than
promoting it. Expand the corpus with additional source-inspected, whole-document
split-safe pages; synthetic documents supplement but never replace real labels.

For external evaluation, record source identities, versions and reuse terms, then test without fitting or tuning on those documents. Include the column layouts and source types relevant to the intended use. Keep source PDFs, annotations and generated reports outside the repository.
