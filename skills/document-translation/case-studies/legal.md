# Agreements and conditions

Decision to practice: Defined parties, may/must, exceptions and time windows.

Use the author-owned paired text in [paired-cases.json](../examples/paired-cases.json), domain key `legal`. Read the source as a coherent passage; establish faithful meaning before interpretive wording. These are fictional fixtures, not domain advice.

Acceptance: Keep the initial 6-month exception, 30-day written notice, 14-day deposit rule and documented deductions. Do not broaden the clause into a general statement about all termination rights.

Common review: no omitted condition, invented context or changed attribution; numerical differences require explanation. Keep stable IDs and source locators. The same pipeline applies; this case adds review attention, not a specialized parser or mandatory style. Compare both target editions with the source, not merely with each other.
