# Optional presentation profiles

Editorial, accessible and compact are implemented CLI styles. The parallel preset means deliver the separate alignment artifact prominently; it is not a fourth CLI style. JSON profiles are editable reference settings, not auto-loaded configuration.

Presentation changes type, spacing, columns and paper only; it never changes translation completeness. Review two-column ordering and use one column for complex figures or RTL when appropriate. Language, audience and interpretive voice remain explicit project decisions. See [layout rules](../references/layout-and-localization.md) and [demo gallery](../examples/index.html).
