# Design acknowledgments

Author: Yufeng Zhan.

The repository organization was informed by two FonaTech projects requested by the user:

- [DFT_Skills](https://github.com/FonaTech/DFT_Skills), inspected tree commit `4e83be8d4aacf6285ef5b223df43c5adb6fd1f6f`.
- [Academic_Writing_Skills](https://github.com/FonaTech/Academic_Writing_Skills), inspected tree commit `086d3a5cc8d1a002a1f0dcb8df4d193b8423eb1f`.

Applied organizational ideas: portable core with optional platform metadata, progressive disclosure, project-local work outside the skill, stable artifact contracts, explicit validation and separate documentation/case resources. This package's implementation and examples were authored for the general translation task, rather than copied from the scientific workflows.

Clouds_Coder source was inspected statically for skill entrypoints and runtime-contract handling. Claude Code and OpenCode skill documentation informed installation paths. Codex uses the standard skill format and local skill-creator guidance; the official Codex web page did not provide a successful retrievable snapshot in this environment. See platform evidence in validation.

User-supplied HTML layouts and a layout-reference skill archive informed one private document project. Their files, content, brand, specialized rules and original PDFs are excluded from this general repository.
